# Personal Career Bot MVP

Локальный MVP персонального Career Bot для поиска работы. Приложение работает на вашем компьютере, хранит данные в локальной SQLite-базе и не требует передачи пароля hh.ru или других учетных данных на внешний сервер.

## Что умеет MVP

- Импорт карьерного профиля и текста резюме вручную или со страницы резюме hh.ru через расширение.
- Учет общего стажа и разбор требования к опыту в вакансии.
- Разделение вакансий на `Подходит`, `Нужно проверить` и `Не подходит` по жестким условиям и полноте данных.
- Ручное добавление вакансии.
- Импорт вакансий из JSON, CSV или простого текста.
- Фильтры по статусу, источнику, скорингу и поисковой строке.
- Локальный AI-скоринг 0-100 с объяснением.
- Генерация персонального сопроводительного письма только из фактов профиля и резюме.
- Воронка статусов: найдено, подходит, письмо готово, отклик отправлен, интервью, оффер, отказ, архив.
- Архивирование вакансии без удаления, удаление одной вакансии и очистка списка с обязательным подтверждением.
- Анализ полного описания вакансии: требования работодателя, ключевые слова и совпадения, подтвержденные профилем.
- Safe Mode: одиночный отклик готовится для ручной проверки; пакет простых откликов запускается только после одного явного подтверждения пользователя.
- Локальный вход с раздельными профилями и воронками владельца и тестировщика.
- Серверное ограничение AI: владелец работает без внутреннего лимита Career Bot, тестировщик не может расходовать API-токены.
- Архитектура оставляет место для будущих модулей Smart Auto и Telegram.

## Безопасные границы

MVP не реализует:

- обход CAPTCHA;
- обход антибот-защиты;
- автоматическое управление hh.ru в обход правил площадки;
- хранение пароля hh.ru на внешнем сервере;
- скрытую массовую отправку откликов.

Безопасный сценарий сейчас такой: вы импортируете вакансии вручную, через экспорт/копирование или через официально разрешенные способы, бот оценивает их и готовит материалы, а решение об отклике остается за вами.

## Запуск

Самый простой способ на Windows:

```powershell
.\start-career-bot-app.cmd
```

Он сам запустит локальный сервер в фоне и откроет Career Bot как отдельное окно приложения.

Остановить фоновый сервер:

```powershell
.\stop-career-bot.cmd
```

Альтернативный ручной запуск:

```powershell
.\run-career-bot.cmd
```

Если Python доступен в PATH:

```powershell
python career_bot/server.py
```

После запуска откройте:

```text
http://127.0.0.1:8765
```

База создастся автоматически:

```text
data/career_bot.sqlite
```

## Передача другому человеку

Запустите `prepare-career-bot-share.cmd`. В папке `dist` появится чистый ZIP без вашей базы, резюме, паролей, вакансий, сессий и API-ключей. Отправьте именно этот архив вместе с находящейся внутри инструкцией `SHARE_GUIDE.md`. Получатель получит независимую локальную копию Career Bot со своей базой; это не общий сетевой аккаунт и ваши данные между компьютерами не синхронизируются.

При первом открытии Career Bot предложит создать две учетные записи:

- `Владелец` — полный доступ и AI без внутреннего лимита приложения.
- `Тестировщик` — отдельный профиль, вакансии и воронка без доступа к AI-генерации.

Пароли содержат не менее 8 символов и хранятся в базе только в виде PBKDF2-хэшей. Существующий профиль и ранее добавленные вакансии закрепляются за владельцем. Тестировщик начинает с чистого профиля.

Внутренний безлимит не отменяет лимиты и оплату выбранного AI-провайдера. ChatGPT и OpenAI API используют разные системы оплаты; для генерации через API понадобится отдельный API-ключ и баланс платформы.

### Подключение OpenAI

1. Войдите как владелец.
2. Откройте вкладку `ИИ`.
3. Вставьте OpenAI API-ключ, выберите модель и нажмите `Сохранить подключение`.
4. Откройте вакансию и нажмите `Сгенерировать письмо`.

По умолчанию используется экономичная модель `gpt-4o-mini`. Ключ шифруется Windows DPAPI для текущего компьютера и никогда не возвращается в браузер после сохранения. Тестировщик не видит вкладку `ИИ`, не получает ключ и не может вызвать генерацию напрямую через API Career Bot.

Во вкладке `ИИ` отображается число генераций и расход входящих, исходящих и общих токенов. Перед вызовом модели Career Bot отправляет в OpenAI только выбранную вакансию и карьерный профиль текущего владельца.

### Подключение Google Gemini

1. Создайте бесплатный API-ключ в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Войдите в Career Bot как владелец и откройте вкладку `ИИ`.
3. Выберите `Google Gemini`, оставьте модель `gemini-3.1-flash-lite`, вставьте ключ и нажмите `Сохранить подключение`.
4. Откройте вакансию и нажмите `Сгенерировать письмо`.

Ключи OpenAI и Gemini сохраняются отдельно: переключение провайдера не удаляет ранее введенный ключ. Бесплатные лимиты Gemini зависят от модели и проекта. На бесплатном тарифе Google может использовать отправленные данные для улучшения своих продуктов. Перед отправкой внешней модели Career Bot автоматически убирает из текста очевидные телефоны, адреса электронной почты, ссылки и публичные никнеймы; исходный профиль в локальной базе остается без изменений.

### Подключение локальной Ollama

1. Запустите `setup-ollama.cmd`. Если Ollama еще не установлена, откроется официальная страница загрузки.
2. Установите Ollama и снова запустите `setup-ollama.cmd`: помощник загрузит модель `qwen3:8b` размером около 5 ГБ.
3. Перезапустите Career Bot, откройте вкладку `ИИ` и выберите `Ollama · локально`.
4. Оставьте модель `qwen3:8b`, сохраните настройку и сгенерируйте письмо в вакансии.

Ollama работает на этом компьютере через `http://127.0.0.1:11434`, не требует API-ключа и не отправляет резюме внешнему AI-провайдеру. Для видеокарт с 8 ГБ памяти базовый вариант — `qwen3:8b`; установленную `qwen3.5:9b` можно использовать экспериментально на более мощной системе.

Модель прикладывает к каждому использованному факту цитату или близкий фрагмент профиля. Career Bot помечает основания как `Подтверждено`, `Близкий пересказ` или `Нужно проверить`. Полноценное письмо сохраняется даже при предупреждениях, но новые числа, названия инструментов и другие не найденные в профиле или вакансии детали выделяются для обязательной ручной проверки. Внутренний анализ совпадения не попадает в письмо: запрещены служебные обороты вроде `в профиле указано`, `это соответствует требованию` и `я кандидат на позицию`; стиль ориентирован на короткие естественные письма из эталонных примеров.

## Быстрый старт

1. Откройте вкладку `Профиль`.
2. Заполните желаемые роли, навыки, ограничения и вставьте текст резюме.
3. Перейдите в `Импорт` и добавьте вакансии.
4. Откройте `Вакансии`, выберите карточку и посмотрите скоринг.
5. Нажмите `Сгенерировать письмо`.
6. Если письмо подходит, переведите статус в `Письмо готово` или `Отклик отправлен` после ручного отклика.

## Поиск через hh.ru

Во вкладке `Поиск` Career Bot формирует URL с выбранными фильтрами и открывает официальную выдачу hh.ru. Авторизация и возможная CAPTCHA выполняются вручную непосредственно на hh.ru.

Поддержка API hh.ru для приложений соискателей прекращена 15 декабря 2025 года. Поэтому MVP не запрашивает регистрацию приложения работодателя, не имитирует авторизованного соискателя и не обходит защиту площадки.

Основной безопасный сценарий Browser Assist:

1. Сформируйте и сохраните сценарии из целевых ролей профиля.
2. Нажмите `Открыть Browser Assist`: откроется обычная авторизованная выдача hh.ru.
3. Расширение последовательно прочитает видимые карточки и добавит их в локальную базу.
4. После завершения нажмите `Следующий сценарий`; при CAPTCHA пройдите проверку вручную и обновите страницу.
5. Career Bot рассчитает скоринг, подготовит письмо и сохранит статус воронки.

Поисковые сценарии строятся только из целевых ролей и распространенных названий реальных вакансий. Навыки не подставляются в название должности: они используются для скоринга вакансии и подготовки сопроводительного письма. Текущий каталог сфокусирован на менеджменте и может расширяться отдельными профессиональными направлениями.

Альтернативный конструктор принимает свободное описание желаемой работы. Локальная Ollama получает целевые роли, навыки, сильные стороны, ограничения и названия вакансий из локальной базы, затем создает 2–6 реалистичных запросов hh.ru с короткими объяснениями. Одинаковые запросы в одном регионе обновляются, а не дублируются. Один сценарий или весь список можно удалить без удаления вакансий, писем и профиля.

Поля профиля поддерживают поиск по буквам и добавление значений тегами. Навыки предлагаются с учетом выбранных целевых ролей. В профиле и поиске сначала выбирается основной крупный город, а кнопка `Уточнить` открывает полный справочник городов и районов hh.ru. В профиле уточнения сохраняются как дополнительные допустимые локации. При недоступности сети используется локальный резервный список.

### Кнопка прямо на hh.ru

Локальное расширение `hh-career-bot-extension` добавляет кнопку `В Career Bot` в карточки вакансий на hh.ru. Для установки откройте вкладку `Поиск` в Career Bot и нажмите `Установить кнопку на hh.ru`. В открывшемся Edge включите режим разработчика, нажмите `Загрузить распакованное расширение` и выберите открытую папку `hh-career-bot-extension`. После обновления страницы hh.ru кнопка появится в карточках.

Расширение не работает скрыто, не читает пароль и не обходит проверки. Browser Assist действует только в открытой пользователем выдаче и передает вакансии в локальный Career Bot по адресу `127.0.0.1:8765`.

Версия расширения `2.3.3` поддерживает Browser Assist, дополнительные варианты карточек и рекламные ссылки hh.ru. Основная кнопка поиска открывает обычную авторизованную выдачу hh.ru; расширение автоматически собирает видимые вакансии с полными описаниями и предлагает перейти к следующему сценарию только после подтверждения пользователя. Реальной проверкой считается только явная страница или видимый элемент CAPTCHA без карточек вакансий; скрытые элементы сайта больше не вызывают ложную остановку. HTTP 403/429 показывается как временное ограничение фонового чтения, а не как CAPTCHA. Кнопка «Собрать страницу» также доступна для ручного запуска. В личном кабинете и на полной странице своего резюме hh.ru появляется кнопка импорта. Она переносит в единый структурированный текст опыт, образование, курсы, тесты, сертификаты, языки, навыки, раздел «Обо мне», опыт вождения, рекомендации, портфолио и сведения о разрешении на работу, если эти блоки заполнены и видимы на странице. Рекламные блоки hh PRO, статистика и карточки платных курсов отбрасываются. Контактные данные не копируются. Повторное добавление обновляет старую неполную запись без дубля. Safe Apply пытается выбрать сохраненное резюме hh.ru по названию и вставляет только заранее одобренное письмо; финальная отправка выполняется пользователем. Пакет простых откликов после одного явного подтверждения пользователя последовательно вставляет только одобренные письма и отправляет форму лишь при отсутствии вопросов, тестов и дополнительных полей. Сложные формы пропускаются и помечаются для ручной обработки. Если отдельного поля письма нет, расширение пробует открыть только явно обозначенную кнопку чата работодателя и вставить туда тот же одобренный текст; общая навигация hh.ru не используется. Локальный PDF нельзя программно подставить в поле загрузки браузера. Проверки и ограничения hh.ru расширение не обходит. После обновления файлов расширения нажмите `Обновить` на странице `edge://extensions` и перезагрузите открытую страницу hh.ru.

Генерации писем выполняются в фоновой очереди: после нажатия можно перейти к другой вакансии, а статус обновится автоматически. PDF-резюме загружается в профиле и хранится только в `data/resumes`. Перед Safe Apply и пакетным откликом письмо нужно явно одобрить. Из-за ограничений безопасности браузера Career Bot не подставляет локальный PDF в поле загрузки; текущий пакетный режим работает только с текстом сопроводительного письма.

## Форматы импорта

### JSON

Можно вставить массив объектов:

```json
[
  {
    "title": "Product Manager",
    "company": "Acme",
    "location": "Remote",
    "salary": "200000-250000 RUB",
    "url": "https://example.com/job/1",
    "description": "Описание вакансии..."
  }
]
```

### CSV

Поддерживаемые колонки:

```text
title,company,location,salary,url,description,source
```

### Текст

Если вставить обычный текст, приложение создаст одну вакансию из этого текста. Первую строку возьмет как название.

## Архитектура

```text
career_bot/
  server.py              HTTP API, SQLite, локальный скоринг и генерация писем
  static/
    index.html           Интерфейс
    app.js               Клиентская логика
    styles.css           Визуальная система
data/
  career_bot.sqlite      Локальная база, создается при запуске
```

Будущие расширения можно добавлять как отдельные сервисы:

- `connectors/hh_official_api.py` для официальных API или разрешенного импорта.
- `automation/smart_auto.py` для Smart Auto с лимитами, журналом действий и политиками безопасности.
- `integrations/telegram_bot.py` для уведомлений и подтверждений.
- `ai/llm_adapter.py` для внешней или локальной LLM, если пользователь явно подключит ключ.

## Принцип генерации писем

Письмо строится только из:

- карьерного профиля;
- текста резюме;
- фактов из вакансии.

MVP не выдумывает опыт, метрики, компании или навыки. Если данных недостаточно, письмо формулируется осторожно.

Следующий этап генератора строится в четыре шага:

1. Выделить из вакансии задачи, обязательные требования и желательные навыки.
2. Для каждого требования найти подтвержденный факт в резюме или карьерном профиле.
3. Передать модели только найденные пары `требование → факт`, название вакансии и компанию.
4. Проверить готовый текст: каждое утверждение о кандидате должно ссылаться на исходный факт, иначе оно удаляется.

Так модель сможет писать связный текст под конкретную вакансию, сохраняя запрет на выдуманный опыт. Провайдер модели подключается через отдельный адаптер и локально сохраненный ключ пользователя.

Подробный контракт и критерии приемки: [`docs/AI_COVER_LETTERS.md`](docs/AI_COVER_LETTERS.md).

Удаленный многопользовательский режим в текущий MVP не включен. Для него предусмотрен отдельный этап: авторизация, раздельные профили и базы пользователей, HTTPS и безопасное хранение секретов.
