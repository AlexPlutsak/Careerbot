# Career Bot 0.19.1: установка и использование

Эта сборка предназначена для Windows 10/11. Все профили, вакансии, письма и настройки хранятся только на компьютере пользователя в папке `data`.

## 1. Что находится в архиве

- `start-career-bot-app.cmd` — обычный запуск приложения.
- `stop-career-bot.cmd` — полная остановка локального сервера.
- `run-career-bot.cmd` — диагностический запуск с видимым окном.
- `setup-ollama.cmd` — установка бесплатной локальной ИИ-модели.
- `hh-career-bot-extension` — расширение Edge для hh.ru.
- `README.md` — техническое описание возможностей.

Архив чистый: в нем нет профиля автора, вакансий, PDF, базы данных, паролей, сессий и API-ключей.

## 2. Первый запуск

1. Распакуйте ZIP полностью, например в `Документы\Career Bot`. Не запускайте файлы прямо из окна архиватора.
2. Установите Python 3 для Windows с сайта https://www.python.org/downloads/windows/.
3. Во время установки Python включите пункт `Add python.exe to PATH`.
4. Дважды щелкните `start-career-bot-app.cmd`.
5. Разрешите запуск, если Windows покажет стандартное предупреждение для локального файла.
6. Career Bot откроется отдельным окном по адресу `http://127.0.0.1:8765`.
7. При первом запуске создайте владельца и тестового пользователя. Для личной работы используйте владельца: у него доступна настройка ИИ.

Новая локальная база будет создана автоматически в `data\career_bot.sqlite`. Не передавайте эту папку другим людям: в ней находятся личные данные пользователя.

## 3. Подключение бесплатной локальной ИИ-модели

1. Запустите `setup-ollama.cmd`.
2. Если Ollama не установлена, откроется официальный сайт. Установите Ollama и снова запустите `setup-ollama.cmd`.
3. Дождитесь загрузки модели `qwen3:8b` размером около 5 ГБ.
4. Перезапустите Career Bot.
5. Откройте вкладку `ИИ`, выберите `Ollama · локально`, модель `qwen3:8b` и сохраните настройку.

Ollama не требует API-ключа. Для слабого компьютера можно вручную указать `qwen3:4b`. OpenAI и Gemini подключаются на той же вкладке собственным API-ключом пользователя; ChatGPT-подписка не заменяет баланс OpenAI API.

## 4. Заполнение профиля

1. Откройте `Профиль`.
2. Укажите имя, реальные целевые роли, допустимые регионы, зарплату и формат работы.
3. Укажите общий опыт в годах, например `2.5`.
4. Добавьте навыки, сильные стороны и ограничения.
5. Заполните историю работы и текст резюме конкретными задачами, инструментами и результатами.
6. При необходимости загрузите PDF. Он хранится локально и используется как справочный файл; браузер не может автоматически прикрепить его на hh.ru.
7. Нажмите `Сохранить и пересчитать`.

Чем конкретнее профиль, тем точнее скоринг и письмо. Не добавляйте навыки и результаты, которых у вас не было.

## 5. Установка расширения hh.ru в Edge

1. В Career Bot откройте `Поиск` и нажмите `Установить кнопку на hh.ru`.
2. В Edge откройте `edge://extensions`.
3. Включите `Режим разработчика`.
4. Нажмите `Загрузить распакованное расширение`.
5. Выберите папку `hh-career-bot-extension` внутри распакованного Career Bot.
6. Проверьте, что версия расширения — `2.1.0`.
7. Обновите открытую страницу hh.ru.

После обновления расширения в будущем нужно нажать кнопку `Обновить` на странице `edge://extensions`, затем перезагрузить hh.ru.

## 6. Импорт своего профиля с hh.ru

1. Войдите в hh.ru обычным способом.
2. Откройте полную страницу собственного резюме с адресом вида `hh.ru/resume/...`.
3. Нажмите `Импортировать профиль в Career Bot` рядом с заголовком резюме либо `В Career Bot` у нужного резюме в личном кабинете.
4. Вернитесь в Career Bot и проверьте вкладку `Профиль`.
5. Исправьте распознанные поля при необходимости и сохраните профиль.

Расширение передает данные только локальному серверу `127.0.0.1:8765`. Пароль hh.ru оно не читает и не сохраняет.

## 7. Поиск, массовый сбор и оценка вакансий

### Вариант A: Browser Assist

1. Добавьте целевые роли во вкладке `Профиль` и сохраните изменения.
2. Откройте `Сценарии` и нажмите `Взять роли из профиля`.
3. Укажите регион, зарплату, свежесть и формат работы: любой, гибрид, на месте или удаленно.
4. Нажмите `Сохранить сценарии`, затем `Открыть Browser Assist`.
5. Career Bot откроет первый включенный сценарий в обычной авторизованной выдаче hh.ru, а расширение начнет сбор видимых вакансий.
6. После успешного завершения расширение через три секунды само откроет следующий включенный сценарий. Кнопка `Остаться здесь` отменяет переход.

Сценарии можно создавать и обычным текстом: в блоке `Опишите работу, которую хотите найти` укажите желаемые задачи, сферу, формат и ограничения. Локальная Ollama сопоставит описание с профилем и уже импортированными названиями вакансий, после чего сохранит 2–6 поисковых запросов. Кнопка `Удалить` убирает один сценарий, а `Удалить все` очищает только сценарии — вакансии и письма остаются в базе.

Если hh.ru покажет CAPTCHA или ручную проверку, сбор остановится. Пройдите проверку самостоятельно и обновите страницу: расширение не имитирует движения мыши и не обходит защиту сайта.

### Вариант B: ручной сбор открытой выдачи

1. Откройте обычный поиск вакансий на hh.ru и настройте фильтры сайта.
2. В правом нижнем углу нажмите `Собрать страницу`.
3. Не закрывайте вкладку, пока счетчик показывает `Читаю N из M`.
4. Расширение прокручивает ленивую выдачу до лимита, получает полные описания через публичный API вакансий hh.ru, добавляет их в локальную базу и считает дубли отдельно.
5. При CAPTCHA, ограничении API или ручной остановке уже добавленные вакансии сохранятся.
6. Для следующей страницы перейдите на нее вручную и снова нажмите `Собрать страницу`.

Для одной вакансии можно использовать зеленую кнопку `В Career Bot` непосредственно на карточке.

Прямой API сохранен как запасной технический режим внутри блока `Дополнительно: прямой API hh.ru`. Для него нужен реальный контакт в User-Agent; доступность зависит от сети и правил hh.ru.

После сбора откройте вкладку `Вакансии`, отсортируйте результаты по скорингу и используйте фильтры `Подходит`, `Нужно проверить` или `Не подходит`. Откройте карточку и проверьте требуемый опыт, ограничения, ключевые слова и объяснение скоринга.

Фильтры статуса, соответствия, минимального скоринга, источника и текстового поиска применяются автоматически — нажимать Enter или отдельную кнопку не нужно.

`Нужно проверить` означает нехватку или неоднозначность данных, а не автоматический отказ. Всегда сверяйте решение с исходной вакансией.

## 8. Генерация письма и Safe Apply

1. Откройте подходящую вакансию либо на экране `Сегодня` задайте минимальный скоринг для пакетной генерации.
2. Нажмите `Сгенерировать письмо` или `Сгенерировать письма`. Можно перейти к другой карточке: генерация продолжится в очереди.
3. Прочитайте письмо и основания использованных фактов.
4. Отредактируйте текст и сохраните изменения.
5. Нажмите `Одобрить письмо`.
6. Нажмите `Подготовить отклик на hh.ru`.
7. Career Bot сразу изменит статус вакансии на `Отклик отправлен`.
8. На hh.ru проверьте выбранное резюме, вставленный текст и вопросы работодателя.
9. Финальную кнопку отправки нажмите вручную. Если вы отменили отправку, верните статус вакансии вручную.

Career Bot не обходит CAPTCHA, антибот-защиту и ограничения hh.ru. При проверке площадки продолжите вручную.

## 9. Остановка и повторный запуск

- Окно приложения можно закрыть, но сервер может продолжать работать в фоне.
- Для полной остановки запустите `stop-career-bot.cmd`.
- Для следующего запуска используйте `start-career-bot-app.cmd`.
- Актуальная версия отображается мелким текстом внизу левой панели приложения.

## 10. Диагностика

Если приложение не открылось:

1. Запустите `run-career-bot.cmd` и не закрывайте появившееся окно.
2. Убедитесь, что в окне есть строка `Open http://127.0.0.1:8765`.
3. Вручную откройте `http://127.0.0.1:8765`.
4. Если команда `python` не найдена, переустановите Python с включенным `Add python.exe to PATH`.
5. Если порт занят, запустите `stop-career-bot.cmd`, затем повторите запуск.
6. Ошибка фонового запуска записывается в `data\launcher-error.log`.

Если кнопка не появилась на hh.ru:

1. Проверьте версию расширения `2.1.0` в `edge://extensions`.
2. Нажмите `Обновить` у расширения.
3. Перезагрузите вкладку hh.ru сочетанием `Ctrl+R`.
4. Убедитесь, что Career Bot запущен и открывается по адресу `http://127.0.0.1:8765`.

Если массовый сбор остановился с `database is locked`, проверьте, что запущена версия Career Bot `0.19.1` и расширение `2.1.0`, затем повторите сбор. База работает в WAL-режиме, а уже сохраненные ссылки будут распознаны как дубли.

## 11. Резервная копия и удаление

- Для резервной копии при закрытом Career Bot скопируйте всю папку `data` в надежное место.
- Для переноса своих данных на другой личный компьютер перенесите папку `data` отдельно и не передавайте ее посторонним.
- Перед копированием собственной папки `data` полностью остановите Career Bot на обоих компьютерах. В ней находятся профиль, вакансии, письма, учетные записи и загруженное PDF-резюме.
- Сохраненные API-ключи могут быть зашифрованы средствами исходного Windows-профиля и не открыться на другом компьютере. В таком случае удалите старый ключ в настройках ИИ и введите его заново. Ollama-ключа не требует.
- Для полного удаления остановите Career Bot и удалите распакованную папку. Дополнительно удалите расширение на странице `edge://extensions` и Ollama через параметры Windows, если она больше не нужна.
