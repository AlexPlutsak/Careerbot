# Career Bot: запуск на другом Windows-ПК

Это снимок проекта от 5 сентября 2026: сервер 0.21.5, расширение 2.3.6.
Архив содержит личные данные, вакансии и письма. Передавайте его только себе.

1. Распакуйте ZIP целиком, например в `C:\Career-Bot`. Не запускайте файлы внутри ZIP. Не заменяйте им папку с другой рабочей базой.
2. Установите Python 3.12 для Windows, включив `Add python.exe to PATH`. Проверка в новом терминале: `python --version`. Проект использует стандартную библиотеку Python, установка pip-зависимостей не требуется. Если Codex уже установил свой Python, существующий запускатель умеет его находить.
3. Установите и запустите Ollama для Windows. Запустите `setup-ollama.cmd` из распакованной папки: он скачает `qwen3:8b`. Нужен интернет для первой загрузки. Веса моделей не включены в ZIP.
4. Дважды нажмите `start-career-bot-app.cmd`. Приложение должно открыться на `http://127.0.0.1:8765/`. Альтернативный запуск из терминала в папке проекта: `python career_bot/server.py`.
5. Войдите прежними логином и паролем Career Bot: учётные записи перенесены. Сеанс браузера не перенесён. В настройках ИИ выберите Ollama и `qwen3:8b`. Если хотите другую модель, сначала установите её через `ollama pull ИМЯ`, затем выберите её в приложении.
6. В Microsoft Edge откройте `edge://extensions`, включите режим разработчика, нажмите «Загрузить распакованное» и выберите папку `hh-career-bot-extension` внутри нового проекта. Проверьте версию 2.3.6. Старую копию расширения отключите, чтобы две копии не работали одновременно.
7. Войдите на hh.ru в Edge самостоятельно и обновите открытые вкладки hh.ru. Расширение привязано к папке: при последующем переносе папки его нужно загрузить заново.
8. Проверьте наличие профиля, вакансий и сохранённых писем. Для первого теста сгенерируйте одно письмо. Массовая автоотправка сейчас отключена в коде; это ожидаемо. Диагностика не отправляет отклики.

## Если не запускается

- `python` не найден: установите Python с PATH и откройте новый терминал.
- Приложение не открылось: прочитайте `data/launcher-error.log`, попробуйте альтернативный запуск из пункта 4 и передайте ошибку Codex.
- Ollama недоступна: запустите её, проверьте `ollama list`. Имя модели в настройках должно совпадать с установленным.
- Extension context invalidated: перезагрузите расширение, затем обновите страницу hh.ru.
- Диагностическая сессия истекла: снова откройте диагностику из карточки Career Bot; срок сессии 15 минут.
- Не помните пароль Career Bot: не удаляйте базу; попросите Codex подготовить восстановление доступа с сохранением данных.

## Что перенесено

Исходники, расширение, тесты, документы, согласованный SQLite-снимок профилей, вакансий, писем и журналов. Снимок сделан SQLite backup, включая изменения из WAL.
В копии очищены сеансы входа и одноразовые ссылки отправки, удалены сохранённые ключи внешних ИИ (они привязаны к старому Windows); выбран локальный провайдер Ollama. Незавершённые очереди остановлены, чтобы они не продолжались при первом запуске.
Исходная база на старом ПК не изменялась. Пароли учётных записей сохранены в виде прежних хешей.

Не перенесены: авторизация hh.ru, установленные Python/Ollama/Edge, веса моделей, старые ZIP, резервные копии, временные каталоги и PID-файл. Новые изменения после создания ZIP в него не попадают.

Для продолжения разработки откройте распакованную папку в Codex и отправьте: «Прочитай CODEX_HANDOFF.md, проверь текущее состояние проекта и продолжи с приоритетов аудита. Не включай массовую отправку до проверки её сценариев».
